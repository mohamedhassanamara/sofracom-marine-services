# Phase 7: staff app alignment

Repository: `../../IdeaProjects/sofracom_admin_pp`, new branch **`redesign`** (two commits, not pushed). Your uncommitted iOS/Android changes there were left untouched.

1. **One status palette.** `lib/status_palette.dart` is generated by `node scripts/export-staff-palette.mjs --write <app dir>` from the website's `lib/design/tokens.js` (`tones` + `statusTone`) and `lib/i18n/en.js` (labels), so the app, the website and the admin use the same colours (badge text on tint, AA) and words (e.g. "Quote sent"). Before: purple/sky colours that existed nowhere else. A website test (`tests/unit/staff-palette.test.mjs`) fails if the app's copy is out of date (skipped when the app isn't checked out next to the site).
2. **Order and quote cards** show the **`SOF-`/`SOQ-` reference** (older documents: the short id), the **customer's note**, and an expandable **History** with every status, time and the note shown to the customer, plus **internal notes** from the admin app (labelled "not shown to the customer").
3. **Quotes tab**: status filter (All quotes / each status), like orders. Quote cards also show the service, boat type/length, product and the **quoted amount + reply** set in the admin.
4. **Wording**: "/admin → Devices" and "admin tool (Operations → Devices) … Add device" now say "admin app (Staff phones) … Create a code" (enrolment screen, revoked message, comments).
5. Prices with **3 decimals** (`DT`), like the website.
6. Fixed while testing: long contact lines (address, notes) overflowed the card at phone width (now wrap); the history tile needed its own `Material`; the ref no longer depends on a `monospace` font (missing on iOS).
